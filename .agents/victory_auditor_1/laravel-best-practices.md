# Laravel Best Practices Skill Summary
Source: /Users/brahmanda/Sites/siap-ai/.agents/skills/laravel-best-practices/SKILL.md

Core Methodology:
- Consistency First: Follow existing patterns in controllers, models, and services.
- Service-Repository pattern: Controllers handle HTTP requests & validation, Services handle business logic, Repositories handle Eloquent/DB queries.
- Security & Authorization: Validate policy checks, RBAC, input sanitization.
- Query optimization & Eloquent relationships: Eager loading, SoftDeletes, proper typing.
