# Naming Conventions

Follow these rules globally across the project:
- **Classes, Models, Controllers, Interfaces**: `PascalCase` (e.g., `ArchiveController`, `AiClassificationService`).
- **Functions and Methods**: `camelCase` (e.g., `getArchives`, `processDocument`).
- **Variables (PHP & JS)**: `snake_case` (e.g., `$file_path`, `let extracted_text`).
- **Helpers**: Helper classes should use `PascalCase` with a `Helper` suffix (e.g., `FormatHelper`). Helper functions should use `snake_case` with a `_helper` suffix.
